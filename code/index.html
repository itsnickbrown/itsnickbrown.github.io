Code

Public versions of the scripts behind the demos. Real partner names, product codes and figures were replaced. The logic is unchanged.

  • partner_insights.py · Builds the Partner Insights page from the ledger
  • partner_insights_template.html · The page the script fills
  • longtail_dashboard.py · Excel dashboard: red/yellow/green, monthly, quarterly, merge map
  • dedupe_ledger.py · One-time cleanup for the double counting
  • build_tracker_demo.py · Daily tracker and seasonal month-end projection
  • tracker_template.html · Tracker page template
  • Update_Tracker.bat · The one-click morning update
  • make_synthetic_ledger.py · Generates the fake ledger every demo runs on
  • synthetic_ledger.csv · The fake ledger itself

Run it yourself: python make_synthetic_ledger.py synthetic_ledger.csv then DEMO_TODAY=2026-11 python partner_insights.py --no-snapshots --out insights.html
