Partner Insights page

One page that answers who is buying, who is new, who came back and who went quiet, for any month. Every row drills down to end users, products and orders.

The problem

Leadership kept asking the same questions. How many partners bought this month? How many are new? Who used to buy and stopped? Each answer meant pulling the POS file into a spreadsheet and building a pivot on the fly, often during the call.

The small resellers made it harder. Two thirds of the active partners bought in a single month all year. A partner is mostly on or off, not up or down, so the usual month-over-month view showed noise.

What I built

A Python script reads the POS ledger and writes one self-contained HTML page. It groups every row by partner and month, then embeds that history as JSON. The browser does the month math, so the month picker re-anchors every card, chart and table without a rebuild.

The definitions were the real work. I wrote them down first and made the code follow them:

  • Repeat: bought this month and in at least one of the 12 months before.
  • Brand new: first POS ever is this month. History starts January 2020.
  • Returning: bought before, but nothing in the 12 months before this month.
  • Gone quiet: bought in 2 or more of the 12 months ending 3 months ago, nothing since.
  • Growing and Declining: trailing 12 vs prior 12, with a 5% flat band.

The three follow-up buckets (Stopped, Gone quiet, Declining) never overlap. Each partner lands in one, checked in that order. That mattered because a BDR worked straight from those lists: 336 partners in three waves, starting with webinar clickers.

One distributor reports the end user in the reseller field. The script drops partners seen only through that distributor, so customers don't get counted as resellers.

How AI fit in

I built this with Claude as a pair programmer. I owned the definitions, the edge cases and the checks. Every number on the page was checked against the ledger before anyone saw it.

The code

The core of the month logic, from the page itself:

function ptype(p, i) {
  if (!p.act[i]) return null;
  if (p.f === i) return 'new';
  return cnt(p, i - 12, i - 1) > 0 ? 'repeat' : 'returning';
}
const isQuiet = (p, i) => cnt(p, i - 14, i - 3) >= 2 && cnt(p, i - 2, i) === 0;
