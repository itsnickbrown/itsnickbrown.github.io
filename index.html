How I use AI.

Practical, checked, and written down so it repeats.

01

Rules before code

Definitions, edge cases and what "right" looks like get settled first. Claude helps build it after that, not before.

02

Every number gets checked

Nothing reaches leadership until it ties back to the source. That habit caught a month in the sales data reading 93% high.

03

Repeat work becomes a skill

Do a task twice and it turns into a reusable workflow, with the steps and format built in. The next run starts close to done.

04

Simple tools win

Python, CSV and single HTML files. No server, no license, and anyone on the team can open the output.
