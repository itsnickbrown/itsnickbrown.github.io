How I use AI.

Practical, checked, and written down so it repeats.

01

I write the rules first

Definitions, edge cases and what "right" looks like come from me. Then Claude writes the first draft of the code.

02

I check every number

Nothing goes to leadership until it ties back to the source. That habit is how I caught a month reading 93% high.

03

I turn repeats into skills

If I do a task twice, it becomes a skill with the steps and format built in, so the next run starts close to done.

04

I keep the stack simple

Python, CSV and single HTML files. No server, no license. Anyone on the team can open the output.
