How I use AI.

Practical, checked, and written down so it repeats.

Most of this work was built while I managed over 1,600 reseller partners at a network diagnostics company that sells through two-tier distribution.

01

Rules before code

I settle the definitions, edge cases, and what "right" looks like first. Then Claude helps build it.

02

Every number gets checked

Nothing reaches leadership until it ties back to the source. That habit caught a month in the sales data reading 93% high.

03

Repeat work becomes a skill

If I do a task twice, it becomes a reusable workflow with the steps and format built in. The next run starts close to done.

04

Simple tools win

Python, CSV files, and single HTML pages. There's no server or license, and anyone on the team can open the output.
